# Poker Study

Учебный тренажёр покерных комбинаций для Windows и Android.

## Возможности

### Windows
- случайные 5-карточные учебные руки;
- определение стандартной комбинации;
- проверка ответа;
- полностью локальная работа.

### Android
- ручной ввод двух карманных карт;
- ввод борда: префлоп / флоп / тёрн / ривер;
- определение текущей лучшей комбинации;
- расчёт распределения итоговых комбинаций к риверу;
- точный перебор на флопе и тёрне;
- Monte Carlo до флопа;
- случайный учебный флоп;
- работа полностью офлайн, без разрешения Internet.

Проект предназначен для обучения и разбора учебных или завершённых раздач. Он не подключается к покер-румам, не распознаёт живой стол и не выдаёт рекомендации по ставкам или действиям во время реальной игры.

## Windows EXE

Во вкладке **Actions** откройте последний успешный запуск **Build Windows EXE** и скачайте артефакт `PokerStudy-Windows`.

## Android APK

Во вкладке **Actions** откройте последний успешный запуск **Build Android APK** и скачайте артефакт `PokerStudy-Android`. Внутри находится `app-debug.apk`.

Для установки APK на Android может потребоваться разрешить установку приложений из выбранного браузера/файлового менеджера в системных настройках Android.

## Исходники Android

Android-проект находится в каталоге `android/` и собирается командой:

```bash
gradle -p android :app:assembleDebug
```

## Тесты Windows-ядра

```bash
pip install -r requirements-dev.txt
pytest -q
```
