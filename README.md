# Poker Study

Windows-тренажёр для изучения названий и распознавания стандартных 5-карточных комбинаций.

## Что умеет

- показывает случайную руку из пяти карт;
- предлагает самостоятельно определить комбинацию;
- по кнопке раскрывает правильный ответ;
- работает полностью локально.

Проект не содержит ставок, советов по игре, анализа соперников, расчёта шансов конкретной раздачи или интеграции с азартными сервисами.

## Запуск из исходников

```bash
python src/poker_study.py
```

## Windows EXE

GitHub Actions автоматически собирает `PokerStudy.exe` на Windows. Во вкладке **Actions** откройте последний запуск **Build Windows EXE** и скачайте артефакт `PokerStudy-Windows`.

## Тесты

```bash
pip install -r requirements-dev.txt
pytest -q
```
