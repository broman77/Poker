# Poker Study

Небольшой Windows-тренажёр для изучения покерных комбинаций и вероятностей.

## Что умеет

- выбор двух карманных карт и до пяти карт борда;
- определение лучшей 5-карточной комбинации;
- точный перебор вероятностей с флопа и позже;
- Monte Carlo до флопа, чтобы интерфейс оставался быстрым;
- случайные учебные раздачи;
- полностью локальная работа, без аккаунтов и подключения к покер-румам.

> Проект предназначен только для обучения математике вероятностей и распознаванию комбинаций. В нём нет ставок, советов «колл/рейз/фолд», анализа соперников или интеграции с азартными сервисами.

## Запуск из исходников

Требуется Python 3.12+ (Tkinter обычно входит в официальный установщик Python для Windows).

```bash
python src/poker_study.py
```

## Windows EXE

GitHub Actions автоматически собирает `PokerStudy.exe` на Windows. Откройте вкладку **Actions**, последний запуск **Build Windows EXE**, затем скачайте артефакт `PokerStudy-Windows`.

## Тесты

pip install -r requirements-dev.txt
pytest -q
